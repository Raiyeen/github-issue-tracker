1. Difference between var, let, and const:
var is the old way and can be declared again and changed, which can create bugs. let is newer and safer because it works only inside the block where it is declared and its value can be changed. const is also block-scoped, but its value cannot be changed after it is assigned.

2.What is the spread operator (...)?
The spread operator is used to copy or combine arrays and objects. It takes all the values from one array or object and spreads them after one by one.

3.Difference between map(), filter(), and forEach():
map() is used to change every item in an array and it returns a new array. filter() is used to select items based on a condition and returns a new array with only those items. forEach() is used to loop through each item in an array, but it does not return a new array.

4.What is an arrow function?
An arrow function is a shorter way to write a function in JavaScript using the => symbol. It makes the code simpler and is often used for small functions.

5,What are template literals?
Template literals are a way to write strings using backticks instead of quotes. They allow you to insert variables directly inside a string using ${}, which makes the code easier to read.
